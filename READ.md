# devops project
Project: Git & GitHub Version Control Practice
I created a local DevOps project repository using Git and managed the project using GitHub. First, I initialized a local Git repository and created meaningful commits to track my project changes.

Then, I created a feature branch to develop changes separately from the main branch. After making changes, I committed them and pushed the feature branch to GitHub.

After testing the changes, I merged the feature branch into the main branch. I also simulated a basic merge conflict by modifying the same file in different branches. I resolved the conflict manually, committed the resolved changes, and completed the merge.
Finally, I used Git commands such as `git log`, `git status`, `git diff`, and `git show` to inspect the commit history and identify changed files.

This project helped me understand practical Git workflows such as branching, committing, pushing, merging, conflict resolution, and version history management, which are commonly used in DevOps and CI/CD environments.
